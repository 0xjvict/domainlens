## Codebase Patterns
- Frontmatter: `parseFrontmatter` returns `Record<string, string>`; array fields (tags, related_concepts, enforced_in) use bracket format `[a, b]` parsed via `parseTags`
- Section extraction: `extractSection(body, 'SectionName')` regex `## SectionName\n(content)(?=\n## |\n---|$)` works across all skill file types
- Relations.md parsing: split on `\n(?=## )` for top-level sections; `### Name` for sub-sections within Concept Relations and Cross-Concept Rules
- MCP tool pattern: `server.tool(name, description, { params }, handler)` always returns `{ content: [{ type: 'text', text: JSON.stringify(...) }] }`
